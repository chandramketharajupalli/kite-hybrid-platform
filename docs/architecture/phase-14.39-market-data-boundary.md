# Phase 14.39 market-data boundary

Mode OFFLINE_SYNTHETIC_ONLY. Boundary.acquire always raises ACQUISITION_NOT_AUTHORIZED for instrument master, candles and any other operation. There is no HTTP, broker SDK, credential, environment activation or persistence port. Future genuine adapters require a separate authorized change. Synthetic approval cannot activate them.

The new pipeline composes existing Candle/Series/Session, Calendar, the packaged canonical loader, frozen registry, research.evaluate, costs and qualification. Existing causal execution, portfolio accounting, HALT and multi-session authority are unchanged. Master records follow the canonical 1,115-symbol order; tokens are synthetic, refreshable attributes with generation binding. Raw supplied master bytes are SHA-256 checked before parsing; canonical generation hashes bind parsed content separately. Hashes establish content correspondence, not source authenticity. Historical batch source digests bind the normalized synthetic candle payload, not a claimed original API response.

Mapping validation rejects duplicates, missing/unexpected symbols, invalid tokens, reused tokens against the supplied preceding generation, expiry and future observation. Supplied earlier generation must itself validate. Token changes produce a different generation; candles must match that exact generation, source batch and symbol/token pair. This phase does not authenticate a complete lifetime token history or reconstruct historical identities from current mappings.

Series owns OHLCV, UTC, chronological ordering and expected slots. Calendar owns explicit dated sessions and holidays. Completeness uses Series.quality without interpolating, inserting zeros or generating market calendars. Unknown calendar/listing/suspension or corporate-action evidence prevents COMPLETE. Malformed series produce INVALID; empty evidence produces DATA_UNAVAILABLE; missing slots produce PARTIAL. Validated duplicates/invalid counts are zero; rejected schema errors are recorded as INVALID rather than silently repaired. COMPLETE is scoped to a supplied synthetic calendar only.

Signals use only bars completed by the injected clock. Existing execution uses previous completed candle volume and next opening price. Accepted fills, unresolved exits and paper HALT behavior are preserved through regression tests. No new simulator exists.

Integration covers one canonical symbol, one explicitly fabricated sparse six-month calendar and forty synthetic candles through all six research definitions. Other dates are declared synthetic closed dates. Separate full-universe mapping validation covers all 1,115 symbols. This is not full-universe end-to-end research, genuine NSE calendar coverage, twelve-month ingestion validation, historical profitability or strategy qualification. The 13,380-family evidence remains frozen.
