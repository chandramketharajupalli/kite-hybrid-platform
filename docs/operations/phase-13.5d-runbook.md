Integration fixtures intentionally alter and terminate only their own disposable
writer session. They must never be redirected to an existing database. Unit tests
require no database. Synthetic authenticated state is not a real authenticated
session. A successful receipt remains SYNTHETIC; four funding terms stay unproven.

Expected denials: missing/expired/replayed capability, wrong owner/session/epoch,
unknown HALT, lease loss, unexpected writer, excess observer rights or missing
statistics visibility, unsafe wire logging, wrong route or exhausted budget.
401/403, 429, 5xx, malformed/oversized responses, timeout and response loss never
retry or restore authentication. Post-response state failure rejects the receipt;
post-read integrity is still attempted. Do not repair a denial by relaxing a guard.

Stop on any accidental real endpoint, real credential dependency or unowned JDBC
target before execution. On test failure preserve the sanitized report and mark
incomplete validation; do not promote readiness. Normal test resource scopes close
the loopback server, observer, owner/lease and disposable container. Do not stop
unrelated processes or delete user files as cleanup. Ignored tmp logs and Maven
reports are local synthetic evidence; follow local retention policy, never commit
raw payloads, private hashes or generated bytecode.
