# Corporate-action choices: pending owner selection

A preserve raw unadjusted values; B use provider-adjusted data only with verified convention/version and provenance; C separately versioned local adjustment after explicit methodology approval; D reject unsupported histories. No option is selected by this document. Existing v1 PROVIDER_UNSPECIFIED_NO_LOCAL_ADJUSTMENT is not retroactively relabeled verified raw or provider-adjusted.

All choices require authoritative complete action-source coverage,security identity,raw digest,calendar and retention authority. Announcement,ex/effective,source observation and information availability are distinct. B requires exact provider price/volume basis and raw-to-derived linkage; C requires precision,tick/rounding,fractional-volume,effective-boundary and audit conventions. No automatic formula, transformation or rounding is implemented. Retrospective normalization must be labeled and kept separate from point-in-time historical knowledge.

Risks include double adjustment,future-information leakage,identity conflation and changed signal/cash paths. Owner/governance must explicitly accept supported events and require independent requalification; successful synthetic tests do not make that choice.
