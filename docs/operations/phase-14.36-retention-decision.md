# Retention decision

UNRESOLVED. No genuine data category is approved for retention. This applies separately to raw master CSV, parsed mappings, candle responses, backtest outputs, source hashes, retrieval timestamps, audit logs, temporary files, backups and recovery copies. For each category legal/contractual basis, maximum duration, storage scope and access restrictions remain null until verified. The internal deny-by-default rule is not claimed as a verbatim Zerodha term.

The reported Clause 4(b), permanent-storage and private-use answers prevent inferring unrestricted databases. Daily refresh does not permit indefinite snapshots; historical analysis does not permit permanent candles; private use does not override restrictions. Derived results and audit metadata are not presumed exempt. No automatic backup or replication.

Future policy must bind exact supporting clauses, authorized period and location, access principals, purpose/expiry/revocation triggers, deletion method, verification receipts, replica/backup removal and recovery handling. Restored data must be checked for expiry before use. Missing duration rejects processing; equality at expiry rejects use. A deletion command is not proof of backup erasure. No deletion service or actual data deletion is implemented here. Unsupported periods remain unknown, not invented.
